## 2. 진행 결과 (근거)

**주제 확정:** 영어 뉴스 기사를 제목 기준으로 유사도 분석해 같은 사건끼리 그룹화하고, 사용자 맞춤형으로 추천하는 웹 서비스

- 데이터: Kaggle 등 공개 영어 뉴스 데이터셋 활용
- 유사도 분석: MinHash/LSH로 유사 기사 그룹화
- AI 활용: Z.ai를 활용한 그룹별 분석

**핵심 기능 확정**

1. 유사 뉴스 그룹화: 같은 사건을 다룬 기사를 한 그룹으로 분류
2. 사용자 기반 맞춤 추천: 사용자 열람 이력을 바탕으로 관심 뉴스 그룹 추천
3. 같은 사건 내 정보 충돌 탐지: 같은 그룹 기사들 사이에서 수치나 주장이 엇갈리는 부분(사망자 수, 발표 날짜 등)을 Z.ai로 찾아 표시
   - 예: "A 언론은 300명, B 언론은 250명 보도"
