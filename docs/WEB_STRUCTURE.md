# SameStory 웹 구조 설계

> 같은 사건, 다른 보도를 한눈에
> 영어 뉴스 제목을 MinHash·LSH로 묶어 사건별로 보여주고, 매체 간 수치 차이와 사용자 맞춤 뉴스를 제공하는 웹 서비스

- 배포 주소: https://samestory-news-qa.vercel.app/
- 현재 단계: 화면 구조 및 기능 흐름 설계 (가상 시연 데이터 사용)

---

## 1. 페이지 구성

| 페이지 | 역할 | 주요 구성 요소 |
|---|---|---|
| 홈 | 전체 사건 목록 | 검색창, 분야 필터(World / Politics / Business / Tech / Sports / Health), 사건 카드 목록, 정렬(기사 많은 순 / 제목 순), "함께 비교해 볼 사건" 하이라이트 |
| 사건 상세 | 한 사건에 묶인 기사 비교 | 핵심 요약, 제목 속 수치 차이, 기사 목록과 대표 제목 대비 Jaccard 유사도, 그룹화 방식 설명, 북마크 / 관심 주제 추가 |
| 내 맞춤 | 사용자 관심 주제 기반 사건 목록 | 관심 주제 설정, 관심 분야 사건만 표시 |
| 차이 탐지 | 수치가 엇갈리는 사건만 모아 보기 | 수치 차이 사건 목록, "검토 필요" 표시 |
| 북마크 | 저장한 사건 모아 보기 | 북마크한 사건 카드 목록 (로그인 필요) |

### 공통 영역
- 상단: 로고, 주 메뉴, 서비스 안내, 데이터 업로드
- 공유 데이터 영역: 데이터셋 선택, 공유 목록 새로고침, 테스터 로그인
- 사이드바: 내 관심 주제, 수치 차이가 있는 사건, 분석 현황

## 2. 기능 흐름

```
뉴스 데이터 (CSV / 공유 DB)
        │
        ▼
제목 전처리 (소문자화, 토큰화 → 단어 집합)
        │
        ▼
MinHash 서명 생성 (128차원)
        │
        ▼
LSH 버킷팅 → 유사 후보 쌍 추출
        │
        ▼
Jaccard 유사도 ≥ 기준값(기본 40%) 인 후보 연결 → 사건 그룹 생성
        │
        ├──▶ 그룹별 공통 키워드 / 요약 (AI: Z.ai 예정)
        ├──▶ 제목 속 수치 추출 → 같은 단위 수치 비교 → 차이 탐지
        └──▶ 사용자 관심 주제 기준 필터링 → 내 맞춤
```

---

## 3. 핵심 기능 설계

### 3.1 유사 뉴스 그룹화
- 영어 제목을 단어 집합으로 변환 후 128차원 MinHash 서명 생성
- LSH로 후보 쌍만 비교해 전체 쌍 비교 대비 연산량 감소
- Jaccard 기준값은 슬라이더로 조절 (낮출수록 넓게, 높일수록 엄격하게)
- 연결 관계로 묶으므로 그룹 내 모든 제목 쌍이 기준을 넘지 않을 수 있음

### 3.2 같은 사건 내 수치 차이 탐지
- 같은 그룹 제목에서 수치 표현(금액, 인원 수 등)을 추출
- 같은 단위끼리 비교해 값이 다르면 "검토 필요"로 표시
  - 예: `$2 billion` (3개 매체) vs `$1.5 billion` (1개 매체)
- 사실 충돌 판정이 아니라 원문 검토 후보로 안내 (보도 시점 차이 가능)

### 3.3 사용자 맞춤
- 관심 주제를 선택하면 해당 분야 사건을 내 맞춤에서 모아 보기
- 로그인 시 북마크 저장

### 3.4 분석 현황 표시
- 입력 제목 수, LSH 후보 쌍 수, 전체 비교 대비 감소율, 분석 시간
- 분석 결과 내보내기, 기사 2건 이상 그룹만 보기 옵션

## 4. 현재 시연 결과 (가상 데이터 기준)

| 항목 | 값 |
|---|---|
| 입력 제목 | 23개 |
| 생성된 사건 그룹 | 7개 |
| LSH 후보 쌍 | 27개 |
| 전체 비교(253쌍) 대비 감소 | 89% |
| 분석 시간 | 23 ms |
| 수치 차이 탐지 사건 | 2개 |
